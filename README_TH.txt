MyTube Web Project - รุ่นคิวคลิปและเลื่อนคลิป

คุณสมบัติ
- เล่นวิดีโอ YouTube ผ่าน YouTube IFrame Player API
- เพิ่มลิงก์หลายคลิปเข้าคิว
- ปัดขึ้นในกรอบวิดีโอบนมือถือเพื่อไปคลิปถัดไป และปัดลงเพื่อย้อนกลับ
- มีปุ่มก่อนหน้า/ถัดไป
- เมื่อคลิปจบ จะเล่นคลิปถัดไปในคิวอัตโนมัติ
- บันทึกรายการโปรดไว้ในอุปกรณ์ด้วย localStorage
- มีปุ่มเข้าสู่ระบบ Google (ต้องตั้งค่า Client ID ก่อน)

วิธีใช้
1. แตกไฟล์ ZIP
2. เปิดเว็บผ่านโฮสต์ HTTPS เช่น GitHub Pages หรือเว็บโฮสต์ของคุณ (แนะนำ ไม่ควรเปิดด้วย file://)
3. วางลิงก์ YouTube แล้วกด “เพิ่มคลิป” เพื่อใส่คลิปในคิว
4. บนมือถือปัดขึ้น/ลงในกรอบวิดีโอ หรือกดปุ่มก่อนหน้า/คลิปถัดไป
5. เมื่อวิดีโอจบ ระบบจะเล่นคลิปถัดไปในคิวเอง

ตั้งค่า Google Login
1. เข้า Google Cloud Console และสร้าง OAuth Client ID ประเภท Web application
2. เพิ่มโดเมนเว็บไซต์ใน Authorized JavaScript origins
3. นำ Client ID มาแทน YOUR_GOOGLE_CLIENT_ID.apps.googleusercontent.com ใน index.html
4. เผยแพร่เว็บผ่าน HTTPS แล้วทดสอบเข้าสู่ระบบ

ข้อจำกัด
- Google Login ในตัวอย่างนี้ใช้แสดงสถานะผู้ใช้ฝั่งหน้าเว็บ ยังไม่มีระบบ backend หรือฐานข้อมูลผู้ใช้
- YouTube อาจแสดงโฆษณาตามระบบของ YouTube เว็บนี้ไม่ข้ามหรือปิดโฆษณา
- คลิปบางรายการอาจปิดการฝังวิดีโอ ทำให้เล่นบนเว็บนี้ไม่ได้
- การเปลี่ยนคลิปอัตโนมัติจะทำงานเมื่อผู้เล่นแจ้งสถานะว่าวิดีโอจบ และอาจมีข้อจำกัดจาก autoplay policy ของเบราว์เซอร์
